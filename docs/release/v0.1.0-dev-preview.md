## Demonstrated functionality

On Arch Linux x86_64 with KDE/KWin Wayland and in a Fedora 45 KDE/KWin 6.8.2
Wayland test VM, the same immutable bundle passed fresh isolated installation,
Android 16 readiness, Settings/Contacts frame presentation, ARM64 Native Bridge
fixture execution through Digitalis/Berberis, Android DNS/HTTPS, PipeWire PCM
transport, lifecycle restart/shutdown, presenter ownership cleanup, and
isolated uninstall. The host HTTP probe returned 204 over TLS 1.3. Fedora's
initial zero-frame run occurred while the disposable desktop was locked; the
controlled awake run presented frames and balanced releases.

The source regression run recorded 574 tests with 6 skipped. These results are
bounded to the tested hosts and fixtures; they do not establish universal app,
ARM64, compositor, or distribution compatibility. The accepted Fedora audio
gate proves PCM transport. Human-confirmed audible tones were observed during
an earlier Fedora diagnostic test, not as a new listening test of this exact
candidate.

## Installation

There is no public download. For an authorized local copy, follow the
[portable installation guide](../portable-development-release.md). The quick
install uses the bundle's `./install` script and a user-local workspace,
installation, config directory, and data directory. A source checkout alone
does not contain the Android image or installable runtime.

## Known limitations and security

- The image is a modified Android diagnostic rootfs and is not built from a
  complete reproducible AOSP source graph.
- Runtime security is not approved for untrusted APKs.
- Fedora functional acceptance used temporary SELinux permissive mode inside
  the isolated test VM, restored to Enforcing afterward. Fedora Enforcing
  compatibility is deferred and not claimed.
- Optional keystore tracing exceeded a stop timeout; the normal untraced
  lifecycle passed.
- Bundle hashes provide integrity relative to the included manifest, not
  publisher authentication.
- Cross-version migration, production certification, broader Linux/compositor
  coverage, and runtime security hardening are outside this accepted preview.

modify, or redistribute AaaS-authored code is granted by this repository. The
candidate bundle is **not cleared for public binary redistribution**. Its
