| Full binary bundle | Not approved | Android and third-party provenance/license obligations are unresolved; runtime security and publisher authenticity are not approved. |

No bundled third-party component is counted as cleared for redistribution. The
nine license texts identified elsewhere in the repository cover only their
respective upstream works; their presence does not license AaaS source or the
Android image. Resolve component licenses, notices, source-offer obligations,
Android image provenance, and proprietary terms from authoritative records. If
the image cannot be redistributed, implement and test a lawful user-side
acquisition/build workflow before using it in a public installation process.
